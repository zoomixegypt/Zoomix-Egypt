# Unused

This folder is outside the active ZOOMIX implementation path.

- `build-template-old/` is a previously generated build output from the original template.
- `assets-template-old/` is reserved for old template assets if they are recovered from Git or another snapshot.
- Do not import files from this folder into the active app unless explicitly reviewed.

The active implementation lives in `src/`, `public/`, and the project root configuration files.
